# Purpose

Burton Workspaces, Burton.work, is a business OS built for the AI age with a deep commitment to sovereign data with honest edges. By honest edges we mean a transparent, audit-able trail of what comes in, what goes out, and who has access to the data.

Burton Workspaces is an open-source, MIT-licensed business automation stack you can self-host or have hosted: a team workspace for CRM, content, wiki, mail, and automations, with markdown and YAML in git as the system of record. Burton is the screen — create, publish, configure, manage, and communicate, with an Agent that talks MCP — and Rabun is the headless engine that runs ETL, workflows, and workers beside it.

Install with one curl on Ubuntu, runs on Postgres and yaml files, in the cloud or on a machine you own, and keep compounding knowledge from conversations, agents, and content without locking it in a proprietary store.
